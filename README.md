# EVIDENCIA_DAGV_COMPUTACI-N_EN_JAVA
Aquí haré la evidencia 4 donde será un sistema de citas médicas

## Instalación y configuración
- Instalar JDK 11
- Instalar IntelliJ IDEA
- Instalar Git
- Clonar el repositorio

## Uso del programa
Este programa permite:
- Dar de alta doctores
- Dar de alta pacientes
- Crear citas médicas
- Relacionar doctor y paciente
- Control de acceso mediante usuarios administradores
